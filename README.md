## 참고사항

- 뉴스 스크래핑 대상 사이트(Daum, Nate)는 마크업 구조가 수시로 바뀔 수 있어, 실행 시점에 따라 결과가 달라지거나 셀렉터를 다시 확인해야 할 수 있습니다.
- 2-2 웹툰 다운로드 결과 이미지는 `img/` 폴더에 저장됩니다.
